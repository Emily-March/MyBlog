玻璃拟态并不只有冰冷的蓝灰色。通过暖色背景、克制的透明度和柔和阴影，它也可以成为个人博客里很有温度的视觉语言。

## 先建立颜色层级

页面需要明确区分背景、卡片、正文和强调色。不要依赖单一的透明白色解决所有层级。

```css
:root {
  --background: #f7f2ea;
  --surface: rgba(255, 253, 248, 0.74);
  --brand: #ed8734;
  --border: rgba(229, 217, 199, 0.94);
}
```

## 玻璃效果只是辅助

`backdrop-filter` 应当帮助内容从背景中分离，而不是抢走文字的注意力。

| 属性 | 推荐范围 | 作用 |
| --- | --- | --- |
| blur | 12–24px | 柔化背景细节 |
| saturation | 110–150% | 保留颜色活力 |
| alpha | 0.65–0.92 | 控制卡片可读性 |

## 保持交互一致

圆角、边框和悬浮动画应当来自同一套设计变量。统一比复杂更重要。
